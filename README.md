# Team Drop Words

떨어지는 단어를 입력해 파괴하는 실시간 팀 대결 타자 게임.
**로그인 없이 QR 스캔 또는 링크 접속만으로** 바로 참여합니다.

- 서버가 Source of Truth — 단어 생성·낙하·판정·점수를 모두 서버가 계산하고 20Hz로 브로드캐스트
- 클라이언트는 렌더링과 입력 전송만 담당
- DB / Redis 없이 인메모리 상태로 동작 (동시 접속 100명 규모 타깃)

## 실행

### 권장 — 터널 (인증서 경고 없음, 다른 네트워크에서도 참여 가능)

```bash
npm install
npm run tunnel
```

서버와 Cloudflare 임시 터널을 함께 띄우고, 발급된 `https://xxx.trycloudflare.com` 주소로
**PC 화면의 QR과 공유 링크가 자동으로 교체**됩니다. LTE로도 참여할 수 있습니다.

### LAN 전용

```bash
npm start          # http://localhost:3000
```

같은 Wi-Fi의 휴대폰에서 QR을 스캔해 참여합니다. 자체 서명 인증서라 첫 화면에
보안 경고가 뜨며, `고급 → 계속 진행`을 한 번 눌러야 합니다.

## 브라우저의 HTTPS 자동 승격 대응

Brave·Chrome 등은 `http://` 주소를 `https://`로 자동 승격합니다.
평문 HTTP만 열어두면 QR로 들어온 참가자가 `ERR_SSL_PROTOCOL_ERROR`를 만나게 됩니다.

그래서 서버는 **같은 포트에서 HTTP와 HTTPS를 동시에 받습니다.**
TCP 첫 바이트가 TLS 핸드셰이크(`0x16`)인지 보고 알맞은 서버로 넘기는 방식이라
포트를 하나만 열고도 두 프로토콜을 모두 처리합니다 (`server/index.js`의 `createMultiplexer`).

LAN 접속용 인증서는 이 PC의 IP를 SAN에 넣어 `.certs/`에 자동 생성·캐시됩니다.
경고 자체를 없애려면 위의 `npm run tunnel`을 쓰세요.

### Docker

```bash
docker compose up --build
# 컨테이너는 호스트 LAN IP를 모르므로 QR 주소를 직접 지정한다
PUBLIC_URL=http://192.168.0.10:3000 docker compose up --build
```

### 외부망 공개 (Cloudflare Tunnel)

```bash
# 방법 A — 임시 주소 (계정 불필요). 서버까지 함께 띄운다
npm run tunnel

# 방법 B — 고정 도메인 (Cloudflare Zero Trust 토큰 필요)
echo "TUNNEL_TOKEN=..."   >> .env
echo "PUBLIC_URL=https://game.example.com" >> .env
docker compose --profile tunnel up -d
```

> **이미 다른 cloudflared 터널을 쓰고 있다면**
> `~/.cloudflared/config.yml`의 ingress 규칙이 quick 터널에도 병합되어
> 모든 요청이 마지막 `http_status:404` 규칙으로 떨어집니다.
> `npm run tunnel`은 전용 임시 설정 파일을 `--config`로 넘겨 이를 격리하므로,
> 기존에 돌고 있는 터널에는 영향을 주지 않습니다.

## 게임 규칙

| 항목 | 값 |
|---|---|
| 라운드 | 2분 30초 또는 공동 목숨 10개 소진 시 종료 |
| 팀 배정 | 인원이 적은 팀 자동 배정 (동수면 점수 낮은 팀) |
| 점수 | 글자 수 × 10 × 콤보 배수 |
| 콤보 | 4초 안에 연속 성공 시 누적, 최대 2배 |
| 실패 | 단어가 바닥에 닿으면 양 팀 공동 목숨 1 감소 |
| 재시작 | 라운드 종료 10초 뒤 자동 |

같은 단어가 화면에 동시에 뜨지 않으므로 입력이 모호해지지 않습니다.
같은 단어를 여러 명이 동시에 치면 **먼저 서버에 도착한 사람**이 가져갑니다.

### 난이도 단계

한컴타자의 `자리 → 낱말 → 단문 → 장문` 흐름을 참고해, 라운드가 진행될수록 문제가 길어집니다.

| 구간 | 출제 |
|---|---|
| ~35초 | 짧은 낱말 위주 (`바다`, `구름`) |
| 35~80초 | 보통 낱말 위주 (`알고리즘`, `아이스크림`) |
| 80초~ | 짧은 문장 등장 (`천 리 길도 한 걸음부터`) |

문장은 입력 시간이 필요하므로 낙하 속도를 28% 늦춥니다.

### 타수 · 정확도

한컴타자처럼 **분당 타수(타/분)** 와 **정확도(%)** 를 실시간으로 보여줍니다.

- 타수는 음절을 자모로 분해해 실제 키 입력 횟수로 셉니다 (`server/hangul.js`).
  두벌식 기준으로 겹모음(`ㅘ`)·겹받침(`ㄳ`)은 2타, 된소리(`ㄲ`)는 Shift 조합이라 1타.
  예) `한글` = ㅎㅏㄴ + ㄱㅡㄹ = **6타**
- 정확도 = 맞힌 타수 ÷ (맞힌 타수 + 틀린 입력 타수)
- 라운드 결과표에 참가자 전원의 타수·정확도·맞힘·최고 콤보·점수가 표시됩니다.

### 로그인 없는 기록 유지

로그인은 없지만 브라우저에 다음을 남겨, 다시 접속해도 이어집니다.

- 마지막으로 쓴 닉네임 (자동 생성된 이름 대신 복원)
- 개인 최고 점수 · 타수 · 정확도 → 결과 화면에서 경신 여부 표시

## 조작

- 단어를 입력하고 **Enter** — 한글 IME 조합 확정과 겹치지 않도록 `keyup`에서 처리하므로 Enter 한 번이면 됩니다
- 입력 중인 단어는 화면에서 초록색으로 강조되고, 친 부분까지 색이 채워집니다
- 좌측 하단 닉네임 칩을 누르면 닉네임 변경 / 팀 이동

## 구조

```
server/
  index.js      Express + Socket.io, QR 생성, HTTP/HTTPS 멀티플렉싱, 소켓 이벤트 라우팅
  game.js       게임 상태·루프·판정·지표 (Source of Truth)
  words.js      난이도 단계별 문제 풀 (낱말 / 단문)
  hangul.js     한글 자모 분해 기반 타수 계산
  nickname.js   자동 닉네임 생성 (중복 방지)
  cert.js       LAN 접속용 자체 서명 인증서
scripts/
  tunnel.js     서버 + Cloudflare 임시 터널 동시 실행
public/
  index.html    플레이 화면 (상단 QR/점수판, 중앙 캔버스, 하단 입력)
  app.js        캔버스 렌더링, 소켓 수신, 입력 처리
  style.css     다크 테마 + 모바일 반응형
```

### 소켓 이벤트

| 방향 | 이벤트 | 내용 |
|---|---|---|
| S→C | `welcome` | 자동 생성된 내 닉네임·팀, 참여 URL |
| S→C | `state` | 20Hz 스냅샷 (단어 좌표, 점수, 목숨, 남은 시간) |
| S→C | `roster` | 참가자 순위 (최대 5Hz) |
| S→C | `word:hit` / `word:dropped` | 파괴 / 낙하 이펙트 |
| S→C | `round:start` / `round:over` | 라운드 시작·결과 |
| C→S | `submit` | 입력한 단어 (서버가 검증) |
| C→S | `rename` / `team:switch` | 내 정보 변경 |

좌표는 0~1 정규화 값이라 PC와 모바일이 화면 크기와 무관하게 같은 게임 상태를 공유합니다.
